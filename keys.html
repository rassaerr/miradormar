Technical Room Keys

Overview of keys and access points for the technical rooms of Mirador del Mar.

Electricity Room

  • Location: Ground floor, next to the main entrance
  • Key Holder: Building Manager
  • Purpose: Main electrical panels, breakers, meter access

Water Room

  • Location: Basement level
  • Key Holder: Building Manager
  • Purpose: Main water valves, pressure system, meters

Communications / Telecom Room

  • Location: First floor service corridor
  • Key Holder: Telecom provider + Building Manager
  • Purpose: Fiber distribution, telephone lines, network equipment

General Maintenance Room

  • Location: Parking level
  • Key Holder: Maintenance company
  • Purpose: Tools, cleaning supplies, shared equipment
